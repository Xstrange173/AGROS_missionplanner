# AGROS Mission Control System

A unified system for drone-based agricultural scanning and mission planning.

## Features
- **Live Scanning**: Real-time target detection and visualization.
- **Mission Planning**: Review and filter detected targets for spraying.
- **Mission Generation**: Create standard `.waypoints` files for Mission Planner.
- **Direct Upload**: Send missions directly to the drone via MAVLink.
- **Settings**: Dynamic configuration for MAVLink ports and IP.

## Usage
Run the main script:
```bash
python main.py
```
This will launch the unified **Mission Control Dashboard**.
